# AI Website

This is a simple static website built with HTML, CSS, and JavaScript.

## Project Files
- `index.html` – main page structure
- `style.css` – page styling
- `script.js` – page behavior

## Run Locally
You can preview the site locally by opening `index.html` in a browser, or by serving it with a simple local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Publish to GitHub Pages
1. Push these files to a GitHub repository.
2. Open the repository in GitHub.
3. Go to `Settings` → `Pages`.
4. Select the branch to publish.
5. Save the settings.
6. GitHub will provide a public URL for the site.

## Notes
This project is suitable for static hosting and can be tested publicly using GitHub Pages.
